# Poppi

Poppi is a mobile-first movie recommendation app. This initial version provides
the application shell, design system foundation, and placeholder navigation.

## Local development

Install dependencies and start the development server:

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Useful commands

```bash
pnpm lint
pnpm build
pnpm start
```

## Source structure

- `src/app` — App Router layouts and pages
- `src/components` — reusable layout and navigation UI
- `src/data` — static application configuration
- `src/types` — shared TypeScript types
- `public/assets` — static images and other public media
